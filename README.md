21: The World world map — исследователь связей локаций

Визуальный граф переходов между локациями нелинейного симулятора снов
(в стиле 2kki explorer). Чистый JS + canvas, без зависимостей.

## Запуск
Нужен любой статический сервер (браузер не даёт странице читать файлы через file://):
- `python3 -m http.server 8000` в папке проекта → http://localhost:8000
- либо разместите папку на любом статическом хостинге (GitHub Pages, Netlify, nginx).

## Обновление карты
Структура графа полностью пересобирается парсером при каждой загрузке страницы:
правьте `data/map.txt` — после F5 граф перестроится. Никаких встроенных копий
и генераторов не требуется.
Строки переходов с `[?]` в цели (сомнительные связи) в граф не включаются.

Парсер понимает:
- заголовки локаций `name [описание]:` (текст в квадратных скобках — описание, не влияет на граф);
- блоки версий `v1:` … `v4:` (цвет ноды);
- переходы `триггер - цель    param +N` (эффекты через 2+ пробела/таб);
- развилки целей `room(day)/room(nightmare)` (создаётся два ребра);
- цепочки `a -> b -> c`;
- метки версий целей `(v2)`–`(v4)` и примечания `[?]` отбрасываются;
- всё после строки `***` игнорируется (мета-информация, не переходы).

## Возможности
- Раскладки графа: **конус (3D-дерево, по умолчанию)** — классический cone tree:
  дети каждой ноды раскладываются по кольцу под родителем, сектор кольца
  пропорционален размеру поддерева, поэтому дерево занимает объём по трём осям;
  в 2D проецируется «сбоку» — от головной ноды по ответвлениям вниз.
  Также: **радиальная** (ярусы — кольца) и **force-directed**.
  Недостижимые из room локации (arcfinal, hivemind, skyscraper) выносятся
  в отдельный ярус/кольцо.
- Сортировка соседей в дереве/радиальной раскладке: по порядку в файле, по имени,
  по версии (v1→v4), по числу переходов (хабы ближе к корню), по сумме эффектов,
  В конусной раскладке сортировка задаёт порядок ветвей по кольцу, а объём сектора
  определяется размером поддерева.
- 3D-проекция: переключатель «3D» — камера управляется мышью как в 3D-редакторах:
  ЛКМ drag — орбита (dx → ось Y, dy → ось X), СКМ drag — панорама, ПКМ drag — долли
  (вертикаль движения меняет дистанцию камеры), колесо — зум; кнопка «⟲ камера» —
  сброс углов + фит, двойной клик по канвасу — фит. Контекстное меню на канвасе
  подавлено. Автовписывание срабатывает при смене 2D/3D, раскладки и сортировки;
  в 3D фит измеряет сцену ортографически (без перспективы), поэтому стабилен
  при любом угле камеры, а перспектива на рендере ограничена клампом.
- Ховер по ссылке локации в списках переходов (и в проходе) показывает её скриншот
  рядом с курсором — только если файл в screenshots/ есть; иначе ничего не всплывает.
- 2D: ЛКМ drag по ноде — перемещение ноды, ЛКМ drag по фону — панорама («захват мира»:
  контент тянется за курсором), клик — выбор; колесо — зум (СКМ drag — тоже панорама).
- Поиск локации (по имени и описанию).
- Кратчайший путь (BFS по направленным рёбрам) между двумя любыми локациями,
  подсветка на графе + список шагов с триггерами.
- Режим «Проход»: последовательное перемещение от локации к локации с накоплением
  значений abyss / surface / lucid / gestalt / SAN. Условия вида `abyss > 4`, `abyss 7-15`
  на переходах подсвечиваются (зелёное/красное); «строгий режим» блокирует
  переходы с невыполненными условиями. Есть откат хода.
- Скриншоты вместо подписей: положите картинки в `screenshots/` (см. screenshots/README.txt).
  Если файла нет — остаётся подпись с названием.

## Файлы
- `index.html`, `style.css`, `app.js` — приложение (парсер в начале app.js, чистые функции).
- `data/map.txt` — редактируемый источник карты.
- `data/default-map.js` — встроенная копия карты.
- `screenshots/` — картинки локаций.

## Производительность
- Рендер по требованию: кадр перерисовывается только при изменении состояния
  (мышь, камера, физика), в покое цикл холостой.
- Физика засыпает, когда суммарная скорость нод падает ниже порога.
- devicePixelRatio ограничен 2 (на Retina в разы меньше пикселей на кадр).
- Подписи не рисуются при сильном отдалении (кроме выделенных нод).

## Прочее
- Клик по стрелке на карте открывает панель: ссылки на обе локации перехода
  (клик — выбор и центрирование) и список триггеров с эффектами. Esc / ✕ / клик
  по канвасу — закрыть.
- Фон: WebGL-шейдер (fbm-шум + domain warping — настоящая текучесть) в отдельном
  канвасе 0.35x разрешения (апскейл CSS), кап 30 fps, пауза в скрытой вкладке;
  на рендер дерева не влияет. Чекбокс «фон» в шапке включает/выключает слой.
  Если WebGL недоступен — остаётся CSS-градиент (два вращающихся conic + blur).
- Наведение на локацию в списках переходов (панель локации и проход) подсвечивает
  на карте соответствующую стрелку ледяным цветом.
