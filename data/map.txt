масочник:
чтобы он появлялся в локациях, его нужно освободить. для этого выходим в локацию с дверями и идём в лежачую гуччи-дверь, оказываемся в тюрьме, освобождаем масочника.
0:  room, скетч на стене слева от масок -> arc, звездочёт -> arcmoon, находится ближе всех к божествам. стоит рядом с бутылкой
1:  library, второй ярус. можно пробраться через книгу в turrisastral (room -> arc, солнцеголовый) или карту "мир" в hospital (room, выйти -> Lroom, дальний коридор направо, крайняя правая дверь)
2:  room, выйти -> Lroom -> foxboro -> desertdoors, дверь с двумя масками -> manor, рядом с проходом в main_scene (от спавна влево-назад-вправо, не поворачивая мышку)
3:  room, стойка с фигурками -> mall, дверь за пальмами -> city, посреди банды
4:  room, картина с трусами -> mtSnow, кусок льда рядом с жабой -> spa, на вершине за спавном [факт попадания в локацию засчитывается за нахождение]
5:  room, меч -> random, на крыше здания. можно пробраться только через дорожку из коров, которая спавнится при высоком значении abyss
6:  room, стойка с фигурками -> mall, в гик-магазине
7:  room, карта мира -> library, книга за спавном -> hedgemony, рядом с большой тумбочкой [факт попадания в локацию засчитывается за нахождение]
8:  room, выйти -> окно слева от гитариста -> backyard, портал за деревьями - на мельнице: коровы, налево через забор, упасть на шестиугольник, дойти до портала
9:  awaken, в спальне - можно попасть через кровавый месяц в darker (room, комп -> tv, прыгнуть внутрь колонны из телевизоров -> mallalt, крайний коридор направо, телефон -> tesseract, дверь за деревом)
10: room, выйти -> Lroom -> foxboro, в секрете с nix, за углом рядом с надписью hello
11: room, выйти -> Lroom -> basement, справа от крана три раза ударить по стене. он будет стоять в открытой комнате
12: получить значение abyss больше 20 -> room -> автотелепорт в arcFinal

TextureManager:
в зависимости от значений параметров сновидения, текстуры будут менять свой вид.

abyssLoop:
если значение abyss достигнет 20, будет засчитан abyss-цикл и оно обнулится.
при попадании в room с циклом игрока перекинет в arcFinal, где он найдёт одного из масочников.
